4 Advanced Spatial Viz

To prepare: Watch CRS video. Read Spatial Data Appendix. Complete Moodle checkpoint.

Data Story Critique: USGS Drought Timeline

  • What is the data story? History of US drought over decades as an animated timeline.
  • What is effective? Geographic + temporal combination shows droughts spreading and receding.
  • What could be improved? Color scale needs a more prominent legend; hover tooltips would help.

My Notes

CRS = 3 components:

  1. Ellipsoid — mathematical shape of Earth (WGS84, GRS80)
  2. Datum — anchor point. WGS84 = global/GPS. NAD83 = North America. Mixing datums = ~3–4ft error.
  3. Projection — 3D → 2D. Always distorts one of: angle, area, or distance.

Mercator: preserves direction, distorts size near poles.

Data models:

  • Vector — points (cities), lines (roads), polygons (boundaries). Formats: .shp, .geojson
  • Raster — grid of pixels, each with one value (elevation, temp). Higher resolution = bigger file.

8 Missing Data

To prepare: Read Chapter 18 in D4DS. Complete Moodle checkpoint.

Data Story Critique: Gates Foundation Goalkeepers 2019

  • What is the data story? Global progress on health and poverty with focus on gender and geographic inequality.
  • What is effective? Small multiples with consistent color make country comparisons readable.
  • What could be improved? Too many overlapping labels — interactivity to highlight countries would help.

My Notes

3 Missing Data Mechanisms:

  • MCAR — unrelated to data. Complete case analysis is valid.
  • MAR — related to observed variables. Use imputation.
  • MNAR — related to the missing values themselves. Hardest to handle.

3 Ways to deal with missingness:

  1. Drop (complete case) — easy but loses data; biased if not MCAR
  2. Create a “missing” category — useful when NA is meaningful
  3. Impute — single imputation underestimates uncertainty; multiple imputation (mice package) preferred
naniar::vis_miss(df)           # visual map of NAs
naniar::miss_var_summary(df)   # table by variable
ggplot(df, aes(x = is.na(Ozone), y = Solar.R)) + geom_boxplot()

9 Functions

To prepare: Read Chapter 25 in D4DS, Section 13.1 in R Programming for Data Science. Complete Moodle checkpoint.

Data Story Critique: How Much We Ate — FlowingData

  • What is the data story? US food consumption per capita trends by category over decades.
  • What is effective? Stacked area shows category trends and overall growth simultaneously.
  • What could be improved? Categories are too broad — more granular breakdowns would reveal nuance.

My Notes

If you’ve copy-pasted code 3+ times → write a function.

function_name <- function(input1, input2 = default) {
  # body
  return(output)
}

Scope: objects created inside a function aren’t accessible outside unless returned.

Embrace { } for tidyverse functions:

group_means <- function(df, group_var, mean_var) {
  df |>
    group_by({{ group_var }}) |>
    summarize(mean = mean({{ mean_var }}))
}

if-else:

if (condition) { } else if (other) { } else { }

Note: if() is not vectorized — use if_else() or case_when() inside mutate().

15 Web Scraping

To prepare: Read the rvest vignette “Web scraping 101.” Complete Moodle checkpoint.

Data Story Critique: ArcGIS StoryMap Collection

  • What is the data story? Environmental and geographic stories through interactive maps.
  • What is effective? Map-first approach makes spatial patterns immediately visible.
  • What could be improved? Navigation between stories is not intuitive.

My Notes

Use web scraping only when no API is available. Always check robots.txt first.

CSS selectors: .classname (class), #id (id), a (tag type). Use Selector Gadget Chrome extension to find selectors by clicking.

page <- read_html("https://www.nih.gov/news-events/news-releases")

titles <- page |>
  html_elements(".thumbnail-teaser__heading") |>

links <- page |>
  html_elements("a") |>
  html_attr("href")

Combine with map() and bind_rows() to scrape multiple pages.

17 Effective Viz

To prepare: Read Brent Dykes’s Data Storytelling article on Forbes. Read Section 4.2 from Mastering Software Dev in R.

Data Story Critique: Africa in 100 Years — The Telegraph

  • What is the data story? Projections of Africa’s demographic shift over the next century.
  • What is effective? The long time horizon makes the scale of change viscerally clear.
  • What could be improved? No uncertainty shown — confidence intervals would be more honest.

My Notes

Presenting a visualization:

  1. Motivation & context — why does this question matter?
  2. Orientation — walk through axes, legends, what a point means
  3. Highlights — focus on 1–2 interesting data points and tell the story
  4. Big picture — overall trends, takeaways, implications

6 guidelines for great plots: high data density, clear labels, useful references, highlight interesting aspects, consider small multiples, make order meaningful. Overarching theme: facilitate comparisons.

18 Interactive Viz

To prepare: Listen to Data Stories Episode 127 (timestamps 18–25:30).

Data Story Critique: SDG Index Dashboard

  • What is the data story? Country-level progress toward UN SDG 4 (Quality Education).
  • What is effective? Choropleth map makes geographic disparities immediately visible.
  • What could be improved? Color scale is hard to interpret precisely — a bar chart alongside the map would help.

My Notes

Use interactivity when it allows users to explore data more quickly or deeply than static visuals.

Shiny structure: ui (layout + inputs + outputs) + server (render functions that listen to inputs) + shinyApp(ui, server)

# *Input() functions go in sidebarPanel()
selectInput(inputId = "city", label = "City", choices = cities)

# *Output() functions go in mainPanel()
plotOutput(outputId = "scatter")

# render*() functions go in server
output$scatter <- renderPlot({
  data |> filter(metro_name == input$city) |>
    ggplot(aes(x = distmiles, y = entropy)) + geom_point()
})

plotly: wrap any ggplot in ggplotly() for hover, zoom, pan. Use frame + ids aesthetics for animations.

19 Quality Control

To prepare: No readings — synthesis lesson.

Data Story Critique: Counting Happiness — FlowingData

  • What is the data story? How happiness is distributed across moments of the day from experience sampling data.
  • What is effective? Dot-plot style conveys the distribution intuitively.

My Notes

- *What could be improved?* No uncertainty shown — confidence intervals would be more honest.

### My Notes

**Presenting a visualization:**

1. Motivation & context — why does this question matter?
2. Orientation — walk through axes, legends, what a point means
3. Highlights — focus on 1–2 interesting data points and tell the story
4. Big picture — overall trends, takeaways, implications
